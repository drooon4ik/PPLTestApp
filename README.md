# PPLTestApp

Тренажёр для подготовки к экзамену PPL: экзаменационный режим на 24 вопроса
с отслеживанием прогресса.

## Запуск

```bash
./run            # порт 8000 по умолчанию
./run 8080       # другой порт
```

Затем откройте в браузере: http://localhost:8000

Требуется только Python 3 (сторонние пакеты не нужны).

## Как это устроено

- `index.html` — само приложение (весь UI и логика на одной странице).
- `server.py` — HTTP-сервер на стандартной библиотеке Python. Отдаёт статику
  и предоставляет API для хранения прогресса.
- `run` — скрипт-обёртка для запуска сервера.
- `study_data.json` — данные с вопросами, которые загружает приложение.

## Хранение прогресса

Прогресс хранится на сервере в файле `progress.json` (один общий профиль),
поэтому не зависит от порта или браузера и сохраняется между запусками.

API:

- `GET /api/progress` — получить текущий прогресс (JSON-объект).
- `POST /api/progress` — сохранить прогресс (тело запроса — JSON-объект).

Если сервер недоступен, приложение использует `localStorage` браузера как
запасной вариант.
